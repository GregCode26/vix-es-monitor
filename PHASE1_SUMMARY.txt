📊 DATA FLOW
═════════════════════════════════════════════════════════════════════════════════

Initialization:
  1. MockDataProvider created
  2. 20 initial candles generated
  3. First snapshot displayed

Update Loop (every 1 second):
  1. Generate new price (random walk + mean reversion)
  2. Update volatility regime
  3. Generate options chain (±3 strikes)
  4. Calculate GEX per strike
  5. Detect gamma levels
  6. Calculate pressures
  7. Detect market regime
  8. Update React state
  9. Re-render charts


💾 DATA STRUCTURES
═════════════════════════════════════════════════════════════════════════════════

AnalysisSnapshot:
  • timestamp: number
  • marketSnapshot: { timestamp, spot, atmStrike, date }
  • optionsChain: OptionChain[]
  • gammaMetrics: { spot, atm, long/short/call/put gamma, etc }
  • volatilityMetrics: { atmIv, callIv, putIv, ivSpread, ivMomentum }
  • priceCandles: CandleData[]
  • gexBars: GexBar[]

Each snapshot is independent and immutable.

🔧 FORMULAS
═════════════════════════════════════════════════════════════════════════════════

GEX (Gamma Exposure):
  GEX = Gamma × Open_Interest × 100 × Spot² × 0.01

Gamma Pressure:
  • Based on distance to Long/Short Gamma
  • Weighted by volatility regime
  • Trend direction biased
  • Normalized to [-100, +100]

Volatility Pressure:
  • Based on IV expansion/compression
  • Weighted by Put/Call IV imbalance
  • Normalized to [-100, +100]

Market Regime Detection:
  • Automatic based on:
    - Gamma Pressure magnitude
    - Volatility regime state
    - Put/Call IV skew
  • 10 possible regimes
