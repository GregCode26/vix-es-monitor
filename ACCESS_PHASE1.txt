🔍 COME LEGGERE
═════════════════════════════════════════════════════════════════════════════════

GAMMA LEVELS (dalle linee nei chart):

  CYAN (Long Gamma):
    - Tende a stabilizzare movimento UP
    - Se prezzo scende verso cyan, accelera
    - Se prezzo sale da cyan, stabilizza

  VIOLA (Short Gamma):
    - Tende a espandere movimento DOWN
    - Se prezzo sale verso viola, accelera
    - Se prezzo scende da viola, stabilizza

  VERDE/ROSSO:
    - Gamma Call/Put separati
    - Mostrano sbilanciamento put/call

PRESSURE INDICATORS:

  +100 Gamma Pressure = Forte pressione rialzista/espansiva
  0   = Neutrale
  -100 = Forte pressione ribassista/espansiva

  +100 Volatility Pressure = IV in espansione
  0   = IV flat
  -100 = IV in compressione


🛠️ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Se il browser mostra "blank page":
  1. Apri DevTools (F12)
  2. Guarda la console per errori
  3. Controlla che il server sia in esecuzione (porta 3000 o 3001)
  4. Ricarica la pagina (Ctrl+R)

Se il server non parte:
  1. Controlla che Node.js sia installato: `node -v`
  2. Controlla che npm sia installato: `npm -v`
  3. Verifica che il progetto compili: `npm run build`
  4. Uccidi processo Node precedente se bloccato

Se i chart non si rendono:
  1. Controlla che il browser supporti Canvas (tutti i moderni lo supportano)
  2. Verifica che JavaScript sia abilitato
  3. Apri DevTools per errori
